# 🎮 Pokémon Explorer & Merch Store

A fun Pokémon-themed website built using HTML, CSS, Bootstrap, and JavaScript.
This project allows users to search for Pokémon using the Pokémon API and explore Pokémon merchandise through a simple online store interface.


## ✨ Features

* 🔍 Search for any Pokémon using live API data
* 🖼 Display Pokémon sprites and information
* ⚠ Error handling for invalid Pokémon names
* 🛍 Pokémon merchandise store with product pages
* 📱 Responsive Bootstrap layout
* 🎨 Custom CSS styling and animations


## 📄 Pages

### 🏠 Home

* Pokémon-themed hero section
* Website introduction
* External Pokémon resource links

### 📖 About

* Brief history of Pokémon
* Favorite Pokémon showcase with animations

### ⚡ Pokémon Search

* Interactive search bar
* Displays:

  * Name
  * ID
  * Height
  * Weight
  * Front/Back/Shiny sprites

### 🛒 Store

* Merchandise cards
* Product descriptions
* Prices and buy buttons
* Individual product pages
